# 📌 Welcome to PinNote

**PinNote** is your sleek, high-performance, Obsidian-inspired Markdown workspace for Windows with dedicated **desktop floating sticky notes**! Work comfortably in your main vault library, and pop out any note to your desktop whenever you need quick reference while coding, researching, or attending calls.

> [!TIP] Pop Out Note
> **Desktop Sticky Note**: Click **📌 Pop Out Note** in the top bar or press `Ctrl + P` to pop out the active note into its own floating desktop window! Each floating note can be pinned on top, resized, and adjusted for transparency.

---

## 🌟 Key Features

1. **📌 Per-Note Desktop Sticky Windows**:
   - Keep individual notes floating over full-screen apps, IDEs, browsers, or games without cluttering your main workspace.
   - Each note window has its own dedicated Always-on-Top pin button (`#sticky-pin`) and opacity slider (30% - 100%).
   - Press `Ctrl + P` to instantly pop out your active note to a desktop sticky window.

2. **🔄 Two-Way Real-Time Live Sync**:
   - Edits made in a floating sticky note instantly reflect in the main editor, and vice versa! No lost data, no manual reloading.

3. **📝 Obsidian-Grade Markdown Power**:
   - **Interactive Checklists**: Click `- [ ]` checkboxes in the preview or sticky note to check off tasks live!
   - **Wiki-style links**: Use `[[Note Name]]` to quickly link and navigate between notes.
   - **Smart Markdown Keyboard**: Auto-closing brackets & quotes `() [] {} "" '' `` `, Tab/Shift+Tab indentation, and smart Enter list continuation.
   - **Obsidian Callouts**: Beautiful `> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`, `> [!CAUTION]`, and `> [!IMPORTANT]` cards.
   - **LaTeX Math Equations**: Inline `$E=mc^2$` and block `$$ \sum_{i=1}^n i = \frac{n(n+1)}{2} $$` with KaTeX.
   - **Code Highlighting with 1-Click Copy**: Clean syntax-highlighted code blocks with convenient Copy buttons.

4. **🏷️ Organization & Quick Search**:
   - **#tags**: Tag your notes anywhere (e.g. #ideas, #tasks, #work) and filter them from the sidebar tag cloud.
   - **Quick Switcher (`Ctrl + K`)**: Fuzzy search and switch between notes instantly with Arrow Up/Down and Enter.
   - **Inline Renaming**: Double-click any note title in the sidebar or click the note badge in the titlebar to rename!
   - **Sidebar Pinning**: Pin your most important notes to the top of your sidebar library.

5. **☕ Eye-Care Warm White Aesthetic**:
   - A soft, calming, warm paper white aesthetic with rich coffee brown accents and typography — carefully tuned to be gentle on your eyes for long writing and reading sessions.

6. **📂 100% Local File Storage**:
   - All notes are saved as plain `.md` files in your local vault (`Documents/PinNote Vault`). No account, no cloud lock-in, open with Obsidian or VS Code anytime!

## 🚀 Keyboard Shortcuts

| Action | Shortcut |
|---|---|
| Pop Out Note to Desktop | `Ctrl + P` |
| Quick Switcher / Fuzzy Search | `Ctrl + K` |
| New Note | `Ctrl + N` |
| Force Save Note | `Ctrl + S` |
| Toggle Sidebar | `Ctrl + \` |
| Zoom Text In / Out | `Ctrl + =` / `Ctrl + -` |
| Reset Text Zoom | `Ctrl + 0` |
| Bold / Italic Formatting | `Ctrl + B` / `Ctrl + I` |
| Close Modal / Quick Switcher | `Esc` |
